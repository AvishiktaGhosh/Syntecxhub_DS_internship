# Zomato Restaurant Data Analysis (End-to-End EDA)

## Project Overview

This project performs an end-to-end exploratory data analysis (EDA) on a Zomato restaurant dataset to understand pricing trends, customer preferences, ratings behavior, and restaurant distribution across cities and cuisines.

The objective is to clean the dataset, explore patterns, visualize insights, and generate actionable business recommendations.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Key Analysis Performed

* Data cleaning and preprocessing
* Cost and rating category creation
* Distribution of restaurants by cost and city
* Top cuisines and highest rated restaurants
* Impact of online delivery and table booking on ratings
* Votes vs rating relationship

## Key Insights

* Budget and mid-range restaurants dominate the market
* Restaurants offering online delivery tend to have higher ratings
* North Indian, Chinese, and Fast Food cuisines are most popular

## Files Included

* Jupyter Notebook with full code
* Cleaned dataset
* Visual report (PDF)
* Charts and visualizations

## Conclusion

This project demonstrates a complete data analysis workflow including data cleaning, exploratory analysis, visualization, and business insight generation useful for restaurant platforms and food businesses.
