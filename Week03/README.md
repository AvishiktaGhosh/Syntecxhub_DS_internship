Project 2 – Netflix / Media Dataset EDA
Objective
This project performs Exploratory Data Analysis (EDA) on a movie/media dataset to understand content trends, genre popularity, and rating distributions.
Analysis Performed

1. Content Growth Over Time

Analyzed number of movies released per year

Visualized using line chart

Observed sharp growth after 2000

2. Top Genres

Identified most common movie genres

Drama, Comedy, and Action dominate content

3. Most Popular Movies

Extracted top 10 movies by popularity score

Spider-Man: No Way Home ranked highest

4. Language Distribution

English dominates dataset

Other languages appear in smaller proportions

5. Distribution Analysis

Popularity distribution is right-skewed

Most movies have moderate ratings (5–7 range)

Visualizations Used

Line chart → yearly content growth

Bar charts → top genres, languages, popularity

Histogram → popularity & rating distribution

All plots saved as PNG files.

Tools Used

Python

Pandas

Matplotlib

Key Insights

Movie production increased rapidly after 2000

Drama and Comedy are most common genres

Most movies have moderate popularity

Ratings cluster around average values
